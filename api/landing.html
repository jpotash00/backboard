For developers

Add it in an afternoon.

One import behind your cancel button. Offboard runs the interview and the save, then hands your app a structured outcome to act on. You decide what happens next.

$ npm install offboard
cancel-button.js
import Offboard from "offboard";

Offboard.init({ publicKey: "pk_live_…" });

// Behind your “Cancel subscription” button:
Offboard.showCancelFlow({
  userId: "user_123",
  context: { plan: "Starter", mrr: 49, tenure_days: 210 },

  onAccept: (outcome) => applyOffer(outcome),   // they took the save
  onCancel: ()        => completeCancellation() // let them go
});
